# Prompt Library

The **Prompt Library** (`/library`) is Catalyst’s curated and community repository for discovering, bookmarking, and importing pre-engineered prompt workflows.

## Overview

Rather than creating prompts from scratch, the Library enables creators and teams to:
- **Discover Featured Blueprints**: Explore battle-tested prompts designed for complex data analysis, coding challenges, creative writing, and image generation.
- **Search & Filter**: Find prompts by keywords, target models (GPT-4 Turbo, Claude 3.5 Sonnet, Midjourney v6), and topical tags (`#Creative`, `#Coding`, `#Marketing`, `#Data Analysis`, `#Writing`).
- **One-Click Studio Import**: Launch any library template directly into the [Prompt Studio](./studio.md) for custom refinement.

---

## How to Use the Prompt Library

### 1. Browse and Search
1. Navigate to `/library` from the main navigation header.
2. Use the search input (`⌘K` or click search bar) to enter keywords or domain concepts.
3. Filter by category pills (`#Creative`, `#Coding`, `#Marketing`, `#Data Analysis`, `#Writing`) or click **Filters** to narrow down by target AI model.

### 2. Inspect Prompt Details
Click any prompt card to view:
- Description and intended outcome
- Recommended AI model architecture
- Sample variables, system directives, and few-shot examples
- Community metrics (views, saves, copies)

### 3. Open in Studio or Copy
- Click **Open Prompt** or **Use in Studio** to clone the prompt configuration into your active studio session.
- Click the **Copy** action to copy the raw or structured prompt text directly to your clipboard.

---

## Unique Architectural Concepts

- **Direct Studio Interoperability**: Every library prompt can be dispatched into the optimization pipeline without manual copy-pasting.
- **Workspaces Integration**: Curated prompt collections can be saved and organized into dedicated user or team workspaces.
